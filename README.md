# AegisSecureComm

A secure military communication web application developed using Java, JSP, Servlets, JDBC, MySQL, HTML, CSS, and JavaScript.

## Features
- Secure Login System
- OTP Verification
- Encrypted Messaging
- User Dashboard
- Admin Dashboard
- Activity Logs
- Password Security
- Message Management

## Technologies Used
- Java
- JSP & Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Apache Tomcat
